# GIA 도서관 (gia-lib-web)

GIA 학생 도서카드 대출·반납 관리 앱입니다. 운영앱(gia-ops-web)과 **같은 Supabase 데이터베이스**를
쓰고, 화면만 별도로 분리되어 있습니다. 학생 명부·고유번호는 운영앱 것을 그대로 읽어 씁니다.

## 어떻게 쓰나요

도서관 노트북에 USB 바코드 스캐너를 꽂고 이 앱의 **대출·반납** 화면을 열어둡니다.

| 상황 | 하는 일 |
| --- | --- |
| 책을 빌려줄 때 | 학생 도서카드 → 책 바코드 순서로 찍습니다 |
| 책을 반납받을 때 | 책 바코드만 찍습니다 (학생카드 불필요) |
| 처음 보는 책 | 찍으면 "등록되지 않은 책" → **이 책 등록하기** → 제목·저자·표지가 자동으로 채워집니다 |
| 같은 책을 다시 찍으면 | 그 학생의 반납으로 처리됩니다 |
| 카드를 안 가져온 학생 | 이름을 입력하고 Enter — 동명이인이면 골라줍니다 |
| 반납받은 책 | 화면에 📍 구역이 크게 떠서 제자리에 꽂을 수 있습니다 |

화면 커서는 자동으로 입력칸에 머물러 있으므로, 마우스를 만질 필요 없이 계속 찍기만 하면 됩니다.
처리 결과는 큰 글씨와 신호음으로 알려줍니다. `Esc`를 누르면 화면에 떠 있는 학생이 해제됩니다.

## 바코드 체계

- **학생 카드** — 운영앱의 학생 고유번호(`GIA-2026-0001`)를 Code128로 인쇄합니다.
  나중에 출결·행사입장·매점 결제로 확장해도 **같은 카드를 그대로** 씁니다.
  배경 그림을 올리면 그 위에 이름·바코드가 얹혀 인쇄되고, 사진을 넣거나 뺄 수 있습니다.
- **책** — 책 뒷면에 인쇄된 ISBN 바코드를 그대로 씁니다(라벨 부착 작업 없음).
  - ISBN 숫자는 있는데 **바코드가 인쇄되어 있지 않은 책**은 그 ISBN으로 바코드를 만들어 라벨로 뽑습니다.
  - ISBN이 아예 없는 책만 자체 번호(`GIA-B-00001`)를 발급합니다.
- **책장 구역** — 칸마다 `LOC-A-1` 라벨을 붙입니다. 정리할 때 이 라벨을 한 번 찍고 책들을
  이어서 찍으면 전부 그 칸으로 배정됩니다.

## 책 위치(구역)

구역 이름은 자유롭게 정합니다(`A-1` 같은 칸 번호도, `그림책` 같은 분류도 가능). 구역 관리
화면에서 네모를 끌어다 놓으면 **도서관 배치도**가 만들어지고, 책을 찾을 때·반납한 책을 꽂을 때
그 자리가 배치도에서 반짝입니다. 반납받아 아직 안 꽂은 책은 **책 정리 → 반납 정리**에 구역별로
묶여 나옵니다.

## 시작하기

```bash
npm install
cp .env.local.example .env.local   # 운영앱과 같은 Supabase 값을 넣습니다
npm run dev
```

DB 표(`lib_books` / `lib_loans` / `lib_visits` / `lib_settings`)와 보안규칙은 **운영앱 저장소**
(`gia-ops-web/supabase/migrations/20260821000000_library_system.sql`)에서 관리합니다. main에
머지되면 GitHub Actions가 자동으로 반영합니다.

## 휴대폰으로 새 책 등록 (`/m/add`)

아이폰·안드로이드 브라우저에서 `/m` 으로 들어가면 휴대폰 전용 화면이 열립니다.
장서관리 화면의 **📱 휴대폰으로 등록** 버튼을 누르면 QR이 떠서 바로 열 수 있습니다.

1. **바코드 찍기** — 폰 카메라로 책 뒷면 ISBN을 읽습니다. 아이폰 사파리는 브라우저 기본
   바코드 인식이 없어 ZXing 인식기를 그때 불러와 씁니다(`BarcodeScanner.tsx`).
   안 읽히면 ISBN 숫자를 직접 입력할 수 있습니다.
2. **정보 확인** — 제목·지은이·출판사가 자동으로 채워집니다. 구역·권수도 여기서 정합니다.
3. **표지 찍기** — 휴대폰 기본 카메라로 찍고, 파란 네모를 맞춰 **표지 부분만 잘라** 올립니다
   (가로 900px JPG로 줄여 저장). 인터넷에서 표지를 찾은 책은 이 단계를 건너뛸 수 있습니다.

이미 등록된 책을 찍으면 &lsquo;표지만 추가&rsquo;로 넘어가서, 표지가 없던 책을 채워 넣을 수
있습니다. 등록이 끝나면 **다음 책 등록** 버튼으로 바로 이어집니다.

## 화면 구성 (도서관 전용 단말)

데스크에 놓고 학생과 함께 보는 화면이라, 결과를 아주 크게 띄우고 다른 학생 기록은 감췄습니다.
관리 메뉴(장서·설정 등)는 평소 숨어 있다가 오른쪽 위 `☰ 관리`를 누르면 서랍처럼 나옵니다.
브랜드 색과 로고는 운영앱(gia-ops-web)의 남색+금색 팔레트를 그대로 씁니다.

크롬의 **페이지를 앱으로 설치**(PWA)를 쓰면 주소창·탭 없는 전용 창으로 뜹니다
(`public/manifest.json`).

## 폴더 구조

- `src/app/(app)/scan` — 대출·반납 스캔 화면(가장 많이 쓰는 화면)
- `src/app/(app)/loans` — 대출중/연체/전체 기록, 손으로 반납·연장·분실 처리
- `src/app/(app)/books` — 장서 등록·수정, 자체 라벨 인쇄 선택
- `src/app/(app)/students` — 학생별 이용 이력
- `src/app/(app)/find` — 책 찾기(학생도 사용) · 구역 안내
- `src/app/(app)/shelve` — 반납 정리 · 구역 배정 스캔
- `src/app/(app)/locations` — 구역 관리 · 배치도 편집 · 구역 라벨 인쇄
- `src/app/(app)/cards` — 도서카드 배경/사진 설정 + 인쇄할 학생 고르기
- `src/app/(app)/settings` — 대출 규칙(기간·권수·연장·연체 정지)
- `src/app/print/cards` — 카드 규격(86×54mm) 인쇄 시트, A4 한 장에 10장
- `src/app/print/labels` — 책 바코드 라벨(55×26mm) 인쇄 시트, A4 한 장에 30장
- `src/app/print/shelf-labels` — 책장 구역 라벨(90×55mm), A4 한 장에 10장
- `src/components/ShelfMap.tsx` — 도서관 배치도(SVG)
- `src/components/StudentCard.tsx` — 도서카드 한 장(배경·사진·바코드)
- `src/app/m` — 휴대폰 전용 화면(새 책 등록)
- `src/components/BarcodeScanner.tsx` — 폰 카메라 바코드 인식(아이폰 포함)
- `src/components/CoverCapture.tsx` — 표지 촬영 + 잘라내기
- `src/app/api/scan` — 바코드 한 번의 처리를 전부 판단하는 곳(대출/반납/규칙 검사)
- `src/app/api/books/lookup` — ISBN으로 책 정보 자동 조회
- `src/lib/code128.ts` — Code128 바코드를 SVG로 그리는 인코더(외부 라이브러리 없음)
- `src/components/AppShell.tsx` — 상단 바 + 숨김 관리 서랍(도서관 단말용 화면 틀)
- `src/lib/supabase` — 브라우저/서버/미들웨어용 Supabase 클라이언트

## 권한 / 로그인

로그인 화면에 두 가지 방법이 있습니다.

1. **도서관 계정** — `gia-library@giamicro.com` + 비밀번호.
   실제 구글 계정이 아니라 **Supabase Auth 안에만 존재하는 가계정**입니다. 구글 워크스페이스에
   계정을 새로 만들 필요가 없습니다. Supabase 대시보드 → Authentication → Users → Add user
   에서 만들고, `app_users` 표에도 자동으로 등록되어(마이그레이션 ⑩번) **운영앱 계정 관리
   화면에서 함께 보이고 정지시킬 수 있습니다.**
2. **교직원 계정** — giamicro.com 구글 로그인. 운영앱에서 승인된 계정만 들어옵니다.

도서관 가계정이 볼 수 있는 것은 **도서관 표 + 학생 이름·영어이름·학년·반·고유번호**뿐입니다.
운영앱의 사건기록·회의록·보호자 연락처·주소에는 접근할 수 없고(`is_giamicro_user()`에서 제외),
운영앱 화면 로그인도 차단됩니다. 관리자가 운영앱에서 이 계정을 승인 취소하면 도서관 노트북도
바로 막힙니다.

## 아직 안 만든 것 (2단계)

- 도서관 입실 기록 화면 — 표(`lib_visits`)와 권한은 이미 준비되어 있어 화면만 붙이면 됩니다.
- 엑셀로 장서 일괄 등록 / 통계 대시보드 / 인기도서 순위
- 학생 사진 일괄 업로드(지금은 한 명씩 올립니다)
- 출결·행사입장 등 학생카드 확장 기능
